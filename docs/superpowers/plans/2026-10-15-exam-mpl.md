# Exam scores + MPL automatic pass/fail Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let an Admin enter a numeric score per Resident for every exam part, set the MPL per part per PGY once in a central table, and have the server decide pass / not pass and show it beside the score.

**Architecture:** Two additive SQL migrations (central `resident_exam_standards` + per-exam snapshot `resident_exam_mpl`, `pgy_at_exam` locked per participant, outcome computed by new RPCs and guarded by a trigger). A pure front-end module `src/examScoring.js` holds grouping and outcome helpers; new components `ExamStandards`, `ExamScoreEditor`, `MplInputs` plug into the existing `ResidentExams.jsx`. Exams created before this change stay `scoring_mode = 'manual'` and keep today's screens and RPCs untouched.

**Tech Stack:** React + Vite, Supabase (Postgres RPC + RLS), `node --test` (regex tests on source/SQL plus pure-function tests), pnpm lockfile (no new dependency).

**Spec:** `docs/superpowers/specs/2026-10-15-exam-mpl-design.md`

## Global Constraints

- Never run `supabase db push`; each migration is applied alone with `supabase db query --linked -f <file>`; production writes are run by the owner, Claude verifies read-only (CLAUDE.md).
- Order: migration A, migration B, then frontend push (Vercel deploys on push to `main`).
- No local Postgres: SQL is covered by regex tests (`npm test`) plus a rollback behaviour script run on staging by the owner.
- Public repository: no real names, e-mail addresses or HN in code, tests, docs or commit messages.
- Score format: non-negative, at most 2 decimals, not above the part full score (`examScoreError`, which must stay exported from `src/features/ResidentExams.jsx` between `export function examScoreError` and `const today = () =>` because `tests/resident-bugfixes-20260928.test.mjs` evaluates that text).
- Pass rule: score >= MPL; PGY without MPL gives a null outcome shown as "ยังไม่ตั้งเกณฑ์"; PGY levels are 1-4 only.
- UI copy is Thai; outcome label for computed results is "ผ่าน" / "ไม่ผ่าน", legacy manual results keep "ผ่าน" / "ต้องซ่อม" (stored value for both is `remediation`).
- Commit messages end with the two attribution lines from the session reminder (`Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` and the `Claude-Session:` URL).

## Deviations from the spec (apply in Task 8)

1. The spec says `save_resident_exam_results` and `create_resident_exam_event` branch on `scoring_mode`. This plan leaves both legacy functions byte-for-byte untouched (old browser tabs keep working) and adds `create_resident_exam_event_mpl`, `save_resident_exam_scores`, `update_resident_exam_mpl`, `save_resident_exam_standards`. A trigger on `resident_exam_results` rejects any non-`computed` outcome for `mpl` exams, so the legacy save cannot bypass the rule.
2. The column default of `scoring_mode` stays `'manual'`; `create_resident_exam_event_mpl` sets `'mpl'`.
3. The create RPC receives the part list with full scores and MPL values from the browser (pre-filled from the standards, editable per exam) and validates them; it does not read the standards table itself.

## Review Focus

- A Resident promoted after the exam keeps the PGY and MPL used at exam time in the published result and in the Staff PGY filter (Task 2 SQL test, Task 3 grouping test).
- A Resident whose profile has no PGY gets `pgy_at_exam` null and a null outcome ("ยังไม่ตั้งเกณฑ์"), never a silent pass or fail (Task 2, Task 3).
- An old browser tab calling the legacy create/save RPCs cannot produce or alter a computed result (Task 1 trigger test, Task 2 SQL test).
- Boundary decimals: `65.00` vs MPL `65` passes, `64.99` fails, `0` score against MPL `0` passes (Task 3 tests, Task 2 SQL test).
- Editing the MPL after scores are entered recomputes every outcome in the same transaction, and clearing a score removes the result so publish is blocked until complete (Task 2 SQL test, Task 6 wiring test).

Create `supabase/migrations/20261015100000_exam_mpl_schema.sql`:

```sql
-- Exam scores + MPL (minimum passing level). Additive: legacy exams stay
-- scoring_mode = 'manual' and their RPCs are not changed by this file.
begin;

create table public.resident_exam_standards (
  id uuid primary key default gen_random_uuid(),
  exam_type text not null check (exam_type in ('xray_anatomy', 'mcq')),
  part_name text not null check (char_length(btrim(part_name)) between 1 and 120),
  max_score numeric(10,2) not null check (max_score > 0),
  updated_by uuid not null references public.resident_profiles(user_id),
  updated_at timestamptz not null default clock_timestamp()
);
create unique index resident_exam_standards_type_name_unique
  on public.resident_exam_standards(exam_type, lower(part_name));

create table public.resident_exam_standard_mpl (
  standard_id uuid not null references public.resident_exam_standards(id) on delete cascade,
  pgy smallint not null check (pgy between 1 and 4),
  mpl numeric(10,2) not null check (mpl >= 0),
  primary key (standard_id, pgy)
);

alter table public.resident_exam_events
  add column if not exists scoring_mode text not null default 'manual'
    check (scoring_mode in ('manual', 'mpl'));
alter table public.resident_exam_parts
  add column if not exists max_score numeric(10,2) check (max_score is null or max_score > 0);
alter table public.resident_exam_participants
  add column if not exists pgy_at_exam smallint check (pgy_at_exam between 1 and 4);
alter table public.resident_exam_results
  alter column outcome drop not null;
alter table public.resident_exam_results
  add column if not exists outcome_source text not null default 'manual'
    check (outcome_source in ('computed', 'manual'));

update public.resident_exam_participants participant
set pgy_at_exam = profile.pgy
from public.resident_profiles profile
where profile.user_id = participant.resident_id
  and participant.pgy_at_exam is null
  and profile.pgy between 1 and 4;

create table public.resident_exam_mpl (
  event_id uuid not null references public.resident_exam_events(id) on delete cascade,
  part_id uuid references public.resident_exam_parts(id) on delete cascade,
  pgy smallint not null check (pgy between 1 and 4),
  mpl numeric(10,2) not null check (mpl >= 0)
);
create unique index resident_exam_mpl_part_unique
  on public.resident_exam_mpl(event_id, part_id, pgy) where part_id is not null;
create unique index resident_exam_mpl_mcq_unique
  on public.resident_exam_mpl(event_id, pgy) where part_id is null;

alter table public.resident_exam_standards enable row level security;
alter table public.resident_exam_standard_mpl enable row level security;
alter table public.resident_exam_mpl enable row level security;
revoke all on public.resident_exam_standards, public.resident_exam_standard_mpl,
  public.resident_exam_mpl from public, anon, authenticated;
grant select on public.resident_exam_standards, public.resident_exam_standard_mpl, public.resident_exam_mpl to authenticated;

create policy resident_exam_standards_visible on public.resident_exam_standards
  for select to authenticated using (
    (select private.resident_role_is('admin')) or (select private.resident_role_is('staff'))
  );
create policy resident_exam_standard_mpl_visible on public.resident_exam_standard_mpl
  for select to authenticated using (
    (select private.resident_role_is('admin')) or (select private.resident_role_is('staff'))
  );
create policy resident_exam_mpl_visible on public.resident_exam_mpl
  for select to authenticated using (
    (select private.resident_role_is('admin'))
    or (
      private.resident_exam_is_published(event_id)
      and (
        (select private.resident_role_is('staff'))
        or private.resident_is_exam_participant(event_id)
      )
    )
  );

create or replace function private.resident_exam_parse_number(p_value text, p_max numeric, p_label text)
returns numeric
language plpgsql immutable set search_path = '' as $$
declare v numeric;
begin
  if coalesce(p_value, '') !~ '^[0-9]{1,8}(\.[0-9]{1,2})?$' then
    raise exception '% is invalid', p_label;
  end if;
  v := p_value::numeric;
  if p_max is not null and v > p_max then
    raise exception '% must not exceed the full score', p_label;
  end if;
  return v;
end;
$$;
revoke all on function private.resident_exam_parse_number(text, numeric, text) from public, anon;
grant execute on function private.resident_exam_parse_number(text, numeric, text) to authenticated;

-- An MPL exam's outcome is always computed on the server. The legacy save RPC
-- inserts outcome_source = 'manual' (the column default) and is refused here.
create or replace function private.resident_exam_results_mode_guard()
returns trigger
language plpgsql security definer set search_path = '' as $$
begin
  if exists (
    select 1 from public.resident_exam_events e
    where e.id = new.event_id and e.scoring_mode = 'mpl'
  ) and new.outcome_source <> 'computed' then
    raise exception 'MPL exams compute the outcome on the server';
  end if;
  return new;
end;
$$;
create trigger resident_exam_results_mode_guard
  before insert or update on public.resident_exam_results
  for each row execute function private.resident_exam_results_mode_guard();

create or replace function public.save_resident_exam_standards(p_standards jsonb)
returns void
language plpgsql security definer set search_path = public, private, auth as $$
declare
  v_item jsonb;
  v_type text;
  v_name text;
  v_max numeric;
  v_id uuid;
  v_pgy integer;
  v_text text;
  v_key text;
  v_seen text[] := array[]::text[];
  v_mcq_count integer := 0;
begin
  if not (select private.resident_role_is('admin')) then
    raise exception 'Active Admin account required';
  end if;
  if coalesce(jsonb_typeof(p_standards), '') <> 'array' then
    raise exception 'Standards must be an array';
  end if;
  delete from public.resident_exam_standards where true;
  for v_item in select value from jsonb_array_elements(p_standards) loop
    if jsonb_typeof(v_item) <> 'object' then raise exception 'Standard is invalid'; end if;
    v_type := v_item->>'examType';
    v_name := btrim(coalesce(v_item->>'partName', ''));
    if v_type not in ('xray_anatomy', 'mcq') or char_length(v_name) not between 1 and 120 then
      raise exception 'Standard is invalid';
    end if;
    v_key := v_type || ':' || lower(v_name);
    if v_key = any(v_seen) then raise exception 'Standard is duplicated'; end if;
    v_seen := array_append(v_seen, v_key);
    if v_type = 'mcq' then v_mcq_count := v_mcq_count + 1; end if;
    v_max := private.resident_exam_parse_number(v_item->>'maxScore', null, 'Full score');
    if v_max <= 0 then raise exception 'Full score must be greater than zero'; end if;
    insert into public.resident_exam_standards(exam_type, part_name, max_score, updated_by)
    values (v_type, v_name, v_max, (select auth.uid()))
    returning id into v_id;
    for v_pgy in 1..4 loop
      v_text := v_item->'mpl'->>(v_pgy::text);
      if coalesce(btrim(v_text), '') <> '' then
        insert into public.resident_exam_standard_mpl(standard_id, pgy, mpl)
        values (v_id, v_pgy, private.resident_exam_parse_number(v_text, v_max, 'MPL'));
      end if;
    end loop;
  end loop;
  if v_mcq_count > 1 then raise exception 'Only one MCQ standard is allowed'; end if;
end;
$$;
revoke all on function public.save_resident_exam_standards(jsonb) from public, anon;
grant execute on function public.save_resident_exam_standards(jsonb) to authenticated;

commit;
```

-- Exam MPL RPCs. Requires 20261015100000_exam_mpl_schema.sql. The legacy
-- create / save / publish functions are intentionally left as they are.
begin;

create or replace function public.create_resident_exam_event_mpl(
  p_exam_type text,
  p_exam_date date,
  p_title text,
  p_max_score numeric,
  p_parts jsonb,
  p_participant_ids jsonb
) returns uuid
language plpgsql security definer set search_path = public, private, auth as $$
declare
  v_event_id uuid;
  v_part jsonb;
  v_names jsonb := '[]'::jsonb;
  v_position integer := 0;
  v_max numeric;
  v_pgy integer;
  v_text text;
  v_part_id uuid;
begin
  if not (select private.resident_role_is('admin')) then
    raise exception 'Active Admin account required';
  end if;

  set pgy_at_exam = case when profile.pgy between 1 and 4 then profile.pgy end
  from public.resident_profiles profile
  where participant.event_id = v_event_id and profile.user_id = participant.resident_id;

    v_position := v_position + 1;
    if p_exam_type = 'mcq' then
      v_max := p_max_score;
      v_part_id := null;
    else
      v_max := private.resident_exam_parse_number(v_part->>'maxScore', null, 'Part full score');
      if v_max <= 0 then raise exception 'Part full score must be greater than zero'; end if;
      update public.resident_exam_parts set max_score = v_max
      where event_id = v_event_id and sort_order = v_position
      returning id into v_part_id;
    end if;

      v_text := v_part->'mpl'->>(v_pgy::text);

        insert into public.resident_exam_mpl(event_id, part_id, pgy, mpl)
        values (v_event_id, v_part_id, v_pgy, private.resident_exam_parse_number(v_text, v_max, 'MPL'));
      end if;
    end loop;
  end loop;
  return v_event_id;
end;
$$;

declare
  v_event public.resident_exam_events%rowtype;
  v_result jsonb;
  v_resident_id uuid;
  v_part_id uuid;

  v_score numeric;

  if not (select private.resident_role_is('admin')) then

  end if;

  if not found then raise exception 'Exam was not found'; end if;
  if v_event.scoring_mode <> 'mpl' then raise exception 'This exam records outcomes by hand'; end if;
  if v_event.status <> 'draft' then raise exception 'Return the exam to Draft before editing results'; end if;

  for v_result in select value from jsonb_array_elements(p_results) loop
    if jsonb_typeof(v_result) <> 'object'

    end if;
    v_resident_id := (v_result->>'residentId')::uuid;
    select pgy_at_exam into v_pgy from public.resident_exam_participants
    where event_id = p_event_id and resident_id = v_resident_id;
    if not found then raise exception 'Exam result includes a Resident outside this exam'; end if;

    if v_event.exam_type = 'mcq' then
      if v_result->>'partId' is not null then raise exception 'MCQ result is invalid'; end if;
      v_part_id := null;
      v_max := v_event.max_score;
      v_key := v_resident_id::text;
    else
      if coalesce(v_result->>'partId', '') !~* '^[0-9a-f]{8}-[0-9a-f]{4}-[1-5][0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$' then
        raise exception 'X-ray or Anatomy result is invalid';
      end if;
      v_part_id := (v_result->>'partId')::uuid;
      select max_score into v_max from public.resident_exam_parts
      where id = v_part_id and event_id = p_event_id;
      if not found or v_max is null then raise exception 'X-ray or Anatomy part is invalid'; end if;
      v_key := v_resident_id::text || ':' || v_part_id::text;
    end if;
    if v_key = any(v_seen) then raise exception 'Exam result is duplicated'; end if;
    v_seen := array_append(v_seen, v_key);

    v_score := private.resident_exam_parse_number(v_result->>'score', v_max, 'Score');
    v_mpl := null;
    select mpl into v_mpl from public.resident_exam_mpl

        when v_score >= v_mpl then 'pass'
        else 'remediation'
      end,
      'computed', (select auth.uid()), clock_timestamp());
  end loop;
  update public.resident_exam_events
  set updated_by = (select auth.uid()), updated_at = clock_timestamp()
  where id = p_event_id;
end;
$$;

-- exam data is kept. Needs one active Admin and two active Residents.
begin;

create function public.zz_act_as(p_user uuid) returns void language plpgsql as $$
begin
  execute 'reset role';
  perform set_config('request.jwt.claim.sub', p_user::text, true);
  perform set_config('request.jwt.claims', json_build_object('sub', p_user, 'role', 'authenticated')::text, true);
  perform set_config('role', 'authenticated', true);
end;
$$;
create function public.zz_reset() returns void language plpgsql as $$
begin execute 'reset role'; end;
$$;
create function public.zz_fails(p_sql text) returns boolean language plpgsql as $$
begin execute p_sql; return false; exception when others then return true; end;
$$;

do $$
declare
  v_admin uuid; v_r1 uuid; v_r2 uuid; v_r3 uuid;
  v_event uuid; v_part uuid; v_outcome text; v_source text; v_count int; v_mpl numeric;
begin
  select user_id into v_admin from public.resident_user_roles where role = 'admin' and active limit 1;
  select user_id into v_r1 from public.resident_user_roles where role = 'resident' and active order by user_id limit 1;
  select user_id into v_r2 from public.resident_user_roles where role = 'resident' and active and user_id <> v_r1 order by user_id limit 1;
  select user_id into v_r3 from public.resident_user_roles where role = 'resident' and active and user_id not in (v_r1, v_r2) order by user_id limit 1;
  if v_admin is null or v_r1 is null or v_r2 is null or v_r3 is null then
    raise exception 'Need one active Admin and three active Resident accounts';
  end if;
  update public.resident_profiles set pgy = 1 where user_id = v_r1;
  update public.resident_profiles set pgy = 2 where user_id = v_r2;
  update public.resident_profiles set pgy = null where user_id = v_r3;

  perform public.zz_act_as(v_admin);
  perform public.save_resident_exam_standards(jsonb_build_array(
    jsonb_build_object('examType', 'xray_anatomy', 'partName', 'Anatomy', 'maxScore', '100',
      'mpl', jsonb_build_object('1', '60', '2', '65')),
    jsonb_build_object('examType', 'mcq', 'partName', 'MCQ', 'maxScore', '50', 'mpl', jsonb_build_object('1', '30'))));
  if (select count(*) from public.resident_exam_standards) <> 2 then raise exception 'standards not saved'; end if;

      jsonb_build_object('examType','mcq','partName','MCQ','maxScore','50','mpl',jsonb_build_object('1','51'))))$q$)
    is not true then raise exception 'MPL above full score must be refused'; end if;
  -- the refused call rolled back its own delete only inside zz_fails; restore explicitly
  perform public.save_resident_exam_standards(jsonb_build_array(

      'mpl', jsonb_build_object('1', '60', '2', '65'))));

      jsonb_build_object('residentId', %L, 'partId', %L, 'score', '100.01')))$q$, v_event, v_r1, v_part)) is not true

      jsonb_build_object('residentId', %L, 'partId', %L, 'score', null, 'outcome', 'pass')))$q$, v_event, v_r1, v_part)) is not true

  select outcome into v_outcome from public.resident_exam_results where event_id = v_event and resident_id = v_r1;
  if v_outcome is not null then raise exception 'cleared MPL must give a null outcome'; end if;

  -- restore PGY1 MPL, publish, then a promotion must not change the published row
  perform public.update_resident_exam_mpl(v_event, jsonb_build_array(
    jsonb_build_object('partId', v_part, 'pgy', 1, 'mpl', '60'),
    jsonb_build_object('partId', v_part, 'pgy', 2, 'mpl', '55')));
  perform public.set_resident_exam_publication(v_event, true);
  if public.zz_fails(format($q$select public.update_resident_exam_mpl(%L, '[]'::jsonb)$q$, v_event)) is not true
    then raise exception 'MPL edit after publish must be refused'; end if;
  perform public.zz_reset();
  update public.resident_profiles set pgy = 3 where user_id = v_r1;
  perform public.zz_act_as(v_r1);
  select count(*) into v_count from public.list_resident_exam_records() where event_id = v_event;
  if v_count <> 1 then raise exception 'a Resident must see only their own row, got %', v_count; end if;
  select mpl into v_mpl from public.list_resident_exam_records() where event_id = v_event;
  if v_mpl is distinct from 60 then raise exception 'published MPL must stay the PGY-at-exam value, got %', v_mpl; end if;
  if (select pgy_at_exam from public.list_resident_exam_records() where event_id = v_event) is distinct from 1
    then raise exception 'pgy_at_exam must stay 1 after promotion'; end if;
  perform public.zz_reset();
  raise notice 'exam MPL behaviour: all checks passed';
end;
$$;

rollback;

// Pure helpers for exam scores, MPL and pass / not pass. No React, no network.
export const PGY_LEVELS = [1, 2, 3, 4];

const blank = (value) => value === null || value === undefined || String(value).trim() === "";
const cents = (value) => Math.round(Number(value) * 100);

// score >= MPL passes. Both blank/non-numeric -> null ("ยังไม่ตั้งเกณฑ์" / not scored).
export function examOutcome(score, mpl) {
  if (blank(score) || blank(mpl)) return null;
  const s = Number(score);
  const m = Number(mpl);
  if (!Number.isFinite(s) || !Number.isFinite(m)) return null;
  return cents(s) >= cents(m) ? "pass" : "remediation";
}

const NUMBER_FORMAT = /^[0-9]{1,8}(\.[0-9]{1,2})?$/;

export function mplError(value, maxScore) {
  const text = String(value ?? "").trim();
  if (text === "") return "";
  if (!NUMBER_FORMAT.test(text)) {
    if (/\./.test(text) && /^[0-9]+\.[0-9]{3,}$/.test(text)) return "MPL ต้องมีทศนิยมไม่เกิน 2 ตำแหน่ง";
    if (text.startsWith("-")) return "MPL ต้องไม่ติดลบ";
    return "MPL ต้องเป็นตัวเลข";
  }
  if (!blank(maxScore) && Number(text) > Number(maxScore)) return `MPL ต้องไม่เกินคะแนนเต็ม ${maxScore}`;
  return "";
}

export function fullScoreError(value) {
  const text = String(value ?? "").trim();
  if (text !== "" && /^[0-9]+\.[0-9]{3,}$/.test(text)) return "คะแนนเต็มต้องมีทศนิยมไม่เกิน 2 ตำแหน่ง";
  if (!NUMBER_FORMAT.test(text) || Number(text) <= 0) return "คะแนนเต็มต้องเป็นตัวเลขที่มากกว่า 0";
  return "";
}

export const resultKey = (residentId, partId) => `${residentId}:${partId || "mcq"}`;
export const mplMapKey = (partId, pgy) => `${partId || "mcq"}:${pgy}`;

export function mplRowsToState(rows) {
  const state = {};
  for (const row of rows || []) state[mplMapKey(row.part_id, row.pgy)] = String(row.mpl);
  return state;
}

export function stateToMplRows(state) {
  const rows = [];
  for (const [key, value] of Object.entries(state || {})) {
    if (blank(value)) continue;
    const separator = key.lastIndexOf(":");
    const part = key.slice(0, separator);
    rows.push({ partId: part === "mcq" ? null : part, pgy: Number(key.slice(separator + 1)), mpl: String(value).trim() });
  }
  return rows;
}

export const mplFor = (state, partId, pgy) => state?.[mplMapKey(partId, pgy)] ?? "";

export function missingMplCount(cells, state) {
  return cells.filter((cell) => !cell.pgy || blank(mplFor(state, cell.partId, cell.pgy))).length;
}

export function groupExamRecords(records) {
  const events = new Map();
  for (const row of records || []) {
    if (!events.has(row.event_id)) {
      events.set(row.event_id, {
        id: row.event_id,
        type: row.exam_type,
        date: row.exam_date,
        title: row.title,
        maxScore: row.max_score,
        status: row.status,
        scoringMode: row.scoring_mode || "manual",
        participants: new Map(),
        parts: new Map(),
        results: new Map(),
        mpls: new Map(),
      });
    }
    const event = events.get(row.event_id);
    if (!event.participants.has(row.participant_id)) {
      event.participants.set(row.participant_id, {
        id: row.participant_id,
        name: row.resident_name,
        pgy: row.pgy_at_exam ?? row.resident_pgy,
      });
    }
    if (row.part_id && !event.parts.has(row.part_id)) {
      event.parts.set(row.part_id, {
        id: row.part_id,
        name: row.part_name,
        sortOrder: row.part_sort_order,
        maxScore: row.part_max_score ?? null,
      });
    }
    const key = resultKey(row.participant_id, row.part_id);
    if (row.mpl !== null && row.mpl !== undefined) event.mpls.set(key, Number(row.mpl));
    if (row.outcome || (row.score !== null && row.score !== undefined)) {
      event.results.set(key, {
        score: row.score,
        outcome: row.outcome ?? null,
        outcomeSource: row.outcome_source || "manual",
        updatedAt: row.result_updated_at,
      });
    }
  }
  return [...events.values()]
    .map((event) => ({
      ...event,
      participants: [...event.participants.values()].sort((a, b) => a.name.localeCompare(b.name, "th")),
      parts: [...event.parts.values()].sort((a, b) => a.sortOrder - b.sortOrder),
    }))
    .sort((a, b) => `${b.date}:${b.id}`.localeCompare(`${a.date}:${a.id}`));
}

export function participantOutcome(event, participant) {
  const cells = event.type === "mcq" ? [null] : event.parts.map((part) => part.id);
  const outcomes = cells.map((partId) => event.results.get(resultKey(participant.id, partId))?.outcome ?? null);
  if (outcomes.includes("remediation")) return "fail";
  if (outcomes.length && outcomes.every((outcome) => outcome === "pass")) return "pass";
  return "pending";
}

export function outcomeLabel(outcome, source = "manual") {
  if (outcome === "pass") return "ผ่าน";
  if (outcome === "remediation") return source === "computed" ? "ไม่ผ่าน" : "ต้องซ่อม";
  return source === "computed" ? "ยังไม่ตั้งเกณฑ์" : "—";
}
