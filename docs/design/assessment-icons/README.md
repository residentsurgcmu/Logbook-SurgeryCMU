Icons are CC0 according to https://healthicons.org/about (checked 2026-10-20). Website/repository code uses MIT; its supplied LICENSE is preserved separately. We use the icon paths, not the website code.

The bundled React path data retains the original path attributes and 48x48 coordinates of the 13 selected icons. React attributes only rename fill-rule/clip-rule to fillRule/clipRule. Inline currentColor inherits the existing My Space icon color. No external font, image request, HTML injection, ICO conversion or added stroke is used.

Sense approved the G3 organ mapping for the 29 current rows, with one explicit exception: PBA-19 Tracheostomy retains C0's existing airway SVG (24x24, stroke1.6). The G3 ears-nose_and_throat asset is not included. The same organ base may represent multiple procedures; full template titles and existing category labels remain visible. Icons do not represent outcome, completion, authorization or a change of department.
