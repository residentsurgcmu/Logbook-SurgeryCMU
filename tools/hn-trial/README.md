# New Case Presentation — offline Grand Rounds HN rehearsal

This staging-only rehearsal accepts synthetic values such as `DEMO-0123456`. The Resident who owns the case enters the value. The Moderator is a duty in the Grand Rounds room, not an RC account or a seat-system permission. There is no ciphertext download in the app, including for ordinary Admin users.

1. Install both HN migrations on staging in order. Deploy a preview pointing to staging ref `vijxiststybmuchcghux` with `VITE_ALLOWED_STAGING_PROJECT_REF=vijxiststybmuchcghux`, staging publishable key and `VITE_CASE_HN_TRIAL=true`.
2. A DB operator configures the public SPKI in `private.rc_hn_trial_config(public_spki)` and enrolls only verified synthetic case UUIDs in `private.rc_hn_trial_cases(case_id)`. No Moderator assignment is required. Keep the locked private key and passphrase on the department side. The public file generated for the earlier prototype still works; key generation is not required again.
3. Sign in as the test Resident and use the HN panel on the enrolled case. Save `DEMO-0123456`, then replace it with `DEMO-7654321`. Check the Network panel: only ciphertext, public key fingerprint, case ID and revision travel, and a stale save does not overwrite a newer revision.
4. An authorized DB operator runs `select private.rc_hn_trial_export_bundle(array[...verified synthetic case UUIDs...]::uuid[]);` and saves just the returned JSON object to a separate file. The whole request fails if any requested case is missing, deleted, unenrolled, lacks a record, or has a different key. Do not convert that JSON into slide content.
5. On the conference computer, open the updated `moderator.html` locally, select the bundle, enter the visible case code, select the original locked private key and unlock it. No RC sign-in or network connection is needed. Keep the local window off the shared/projector screen. The value clears on case change, tab hide or after 20 seconds. Prepare a fresh bundle after any correction; old copies contain earlier encrypted values and are not revoked remotely.
6. As a second Resident, Staff and Admin, verify that the website shows at most the saved status for an enrolled case and cannot download any ciphertext. Confirm PowerPoint, Excel and normal case responses remain free of HN from this panel. Disable the rehearsal by deleting the config row when finished; separately discard the temporary test bundle.

SQL fixtures cover former Moderator assignments and ordinary accounts, direct grants, selection, deleted cases and stale writes. The offline browser probe covers selecting either of two cases, rejecting missing and duplicate codes and rejecting a changed UUID. These tests do not replace staging JWT/HTTP acceptance. The protection applies to the dedicated HN panel; ordinary notes and attachments must not contain patient identifiers.
